= ADR 002: The Per-Use Checks, the Read and the Signing Use One No-Follow Snapshot
:nofooter:

== Status

Accepted

== Date

2026-10-12

== Context

The work package adds the per-use checks of enrolment files that Milestone 2 left out: owner, mode and no symbolic
link, checked on every use of an enrolment file. The review rounds of the pull request settled on which view of the
file the check, the read and the signing work.

== Decision

* The per-use check (owner, mode, no symbolic link), the content read and the signing work on one no-follow snapshot of the file (`EnrolmentFileCheck`, `EnrolmentSnapshot`).
* The re-baseline refuses an insecure file through the same audited path as the verifier.

The pull request records that the snapshot narrows the window between the check and the read; no further rationale is
recorded.

== Alternatives Considered

Alternatives not recorded.

== Consequences

* The JDK offers no attribute read on an open handle, so the snapshot narrows the window between check and read but does not close it.
* A failed per-use check is refused as `enrolment_insecure`.
