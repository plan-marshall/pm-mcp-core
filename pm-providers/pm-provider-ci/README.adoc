= `pm-provider-ci`
:nofooter:

`pm-provider-ci` holds the shared HTTP base of the CI contract. The native clients of GitHub, GitLab and Sonar send
their requests through it. What the module may depend on is stated in the
https://github.com/plan-marshall/plan-marshall-documentation/blob/main/doc/specification/module-structure.adoc[Module Structure Specification].

== Package

The line is the first sentence of the package's `package-info.java`.

* `de.planmarshall.provider.ci`: the CI contract's shared HTTP base over `cui-http`.

== Build and Test

Run from the root of the repository:

* Tests: `python3 .plan/execute-script.py plan-marshall:build-maven:maven run --command-args "test -pl pm-providers/pm-provider-ci -am"`

The commands for the whole repository are in `CLAUDE.md`.

== Developer Documentation and ADRs

The module has no developer documentation and no ADRs yet. A later plan writes them to
`doc/developer/provider-ci.adoc` and `doc/adr/provider-ci/` of this module. The index of all ADRs of the repository
is link:../../doc/adr/README.adoc[`doc/adr/README.adoc`].
