= `pm-provider-http`
:nofooter:

`pm-provider-http` holds the shared HTTP base of the provider modules over `cui-http`: origin-pinned
authentication, pagination with completeness, conditional requests, rate-limit outcomes with their
reset instant, and redaction. It names no forge and no analysis service; the provider adapters build
their contracts on it. What the module may depend on is stated in the
https://github.com/plan-marshall/plan-marshall-documentation/blob/main/doc/specification/module-structure.adoc[Module Structure Specification].

== Package

The line is the first sentence of the package's `package-info.java`.

* `de.planmarshall.provider.http`: the shared HTTP base of the provider modules over `cui-http`.

== Build and Test

Run from the root of the repository:

* Tests: `python3 .plan/execute-script.py plan-marshall:build-maven:maven run --command-args "test -pl pm-providers/pm-provider-http -am"`

The commands for the whole repository are in `CLAUDE.md`.
