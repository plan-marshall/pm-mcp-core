= `pm-provider-git`
:nofooter:

`pm-provider-git` holds the git contract of the engine and the variant that serves it in process on JGit. It never
starts a process. What the module may depend on is stated in the
https://github.com/plan-marshall/plan-marshall-documentation/blob/main/doc/specification/module-structure.adoc[Module Structure Specification].

== Packages

The line is the first sentence of the package's `package-info.java`.

* `de.planmarshall.provider.git`: the git contract of PM-MCP and its native variant on JGit.
* `de.planmarshall.provider.git.ported` (test tree): the ported-primitive tests of the git contract (PM-TEST-2, PM-MIG-4): Java tests of a primitive whose `plan-marshall` original is classified `Ported` in the migration inventory.

== Build and Test

Run from the root of the repository:

* Tests: `python3 .plan/execute-script.py plan-marshall:build-maven:maven run --command-args "test -pl pm-providers/pm-provider-git -am"`

The commands for the whole repository are in `CLAUDE.md`.

== Test artifact

The test scope is published as the `pm-provider-git:tests` test JAR (the `tests` classifier, built by `verify` and
deployed with the `SNAPSHOT`). It holds the package `de.planmarshall.provider.git.testing.generators` with the
`TypedGenerator<T>` of the transport credential the test classes build by hand (`GitOperations.GitCredential`) and the
`GitGenerators` factory that registers it. The `test-jar` goal includes only this package, so the module's own tests
are not published. No module of this repository consumes it; the assembly `plan-marshall-mcp` may, as a test-scope
dependency of type `test-jar` whose version comes from the root POM's `dependencyManagement`. The artifact is the
operator's decision of 2026-11-06 (PLAN-V2-92); its consumers are recorded in
link:../../doc/adr/012-generator-artifacts.adoc[ADR 012].
