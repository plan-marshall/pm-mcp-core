= `pm-provider-git`
:nofooter:

`pm-provider-git` holds the git contract of the engine and the variant that serves it in process on JGit. It never
starts a process. What the module may depend on is stated in the
https://github.com/plan-marshall/plan-marshall-documentation/blob/main/doc/specification/module-structure.adoc[Module Structure Specification].

== Packages

The line is the first sentence of the package's `package-info.java`.

* `de.planmarshall.provider.git`: the git contract of PM-MCP and its native variant on JGit.
* `de.planmarshall.provider.git.ported` (test tree): the ported-primitive tests of the git contract (PM-TEST-2, PM-MIG-4).

== Build and Test

Run from the root of the repository:

* Tests: `python3 .plan/execute-script.py plan-marshall:build-maven:maven run --command-args "test -pl pm-providers/pm-provider-git -am"`

The commands for the whole repository are in `CLAUDE.md`.
