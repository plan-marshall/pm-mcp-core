= `pm-provider-sonar`
:nofooter:

`pm-provider-sonar` connects the engine to SonarQube and SonarCloud as a code analysis provider. It adapts the
code-analysis and findings contracts of `pm-core`. It is no CI provider; of `pm-provider-ci` it uses the shared HTTP
base alone. What the module may depend on is stated in the
https://github.com/plan-marshall/plan-marshall-documentation/blob/main/doc/specification/module-structure.adoc[Module Structure Specification].

== Package

The line is the first sentence of the package's `package-info.java`.

* `de.planmarshall.provider.sonar`: Sonar (SonarQube and SonarCloud) as a code analysis provider: the adapter of the code-analysis and findings contracts of `pm-core`.

== Build and Test

Run from the root of the repository:

* Tests: `python3 .plan/execute-script.py plan-marshall:build-maven:maven run --command-args "test -pl pm-providers/pm-provider-sonar -am"`

The commands for the whole repository are in `CLAUDE.md`.
