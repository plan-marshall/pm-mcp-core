== Overview

This document specifies the data-driven client profile schema and the on-the-fly placeholder rendering rules for *plan-marshall-mcp* (`PM-MCP`). The detection of a coding agent's environment for the operator checks and the embedded client bundle with its `bundle-manifest.json` schema are specified in the link:../../../plan-marshall-documentation/doc/specification/host-integration.adoc[Host Integration & Bundle Manifest Specification]. A harness is a worker only, never a channel of the operator. By translating vocabulary skills, worker launch prompts, and host tool idioms at request time for the harness a worker's role names, `PM-MCP` serves Claude Code (`claude`), OpenCode (`opencode`), Antigravity (`antigravity`), Codex (`codex`), and every harness the operator adds, concurrently and without static per-runtime corpus generation. Each profile also declares its harness's headless launch contract and its `worker` block (whether the harness may host workers, and the measured per-host values of the task protocol and of supervision), what the machine's onboarding needs to find and check the harness (install locations, version, login, and models probes, model tiers, icon), and how its output maps onto the worker's activity and usage.
