== Overview

This document defines the normative hypermedia state representation format (HATEOAS) and deterministic Token-Oriented Object Notation (TOON) encoding rules for *plan-marshall-mcp* (`PM-MCP`). Every call to `pm_state` or `pm_do` returns an authoritative state representation rendered in TOON containing the scope identifier, closed state and phase names, optional vocabulary skill URI, contextual facts, and the set of valid hypermedia links. Model-facing links are offered only where a model acts, on the task entities a worker holds; the representation of a plan or an epic is a view. The operator's clients receive a representation of their own over the local API, the operator representation with its operator links and its texts as message keys, which this document defines beside the model-facing one and keeps apart from it.
