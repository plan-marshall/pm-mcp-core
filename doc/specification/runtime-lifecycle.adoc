== Overview

This document specifies the lifecycle of the runtime (`pm-mcpd`) as far as the engine module `pm-runtime` implements it: the startup sequence, the per-project recovery with the fencing of worker generations and the requeue of leased tasks, the periodic sweep, the runtime's lifecycle operations (drain, stop, restart, upgrade), the pause and start of a plan with stalled plans as a hold, and the metrics the runtime keeps. The processes, the transport, the local API with its resources and events, the relay and the workers' connections are specified in the link:../../../plan-marshall-documentation/doc/specification/runtime-model.adoc[Runtime & Interaction Model Specification], which this document completes for the engine.
