== Overview

This document specifies the plan unit as a workflow of six phase sub-workflows and their state machines (Phases 1–6), the role whose task does the model work of each state and its fallback while the role is unqualified, the plan outcomes with their fallback routes and remediation policy calls, decisions as operator waits, the operator's waivers and acts, transition guards, the plan instance composition, the Q-Gate validation loop, the change-type and unplanned-change contracts, Phase 5 envelope execution and verification sweep, Phase 6 finalize step ordering bands and step states, `FinalizeStepDescriptor` schema, verdict currency rules, the landing variants, the merge path with the pre-merge review barrier and its waivable gates, and the cross-plan merge mutex for *plan-marshall-mcp* (`PM-MCP`).

In `PM-MCP`, the prose-driven epic loops, phase handshake files (`handshakes.toon`), and intra-phase step-recording rituals (`mark-step-done`, `assert-step-recorded`) of `plan-marshall`'s script architecture are replaced by deterministic server-owned state machines defined in `classpath:/workflows/*.pmwf` and executed by `pm-workflow`. The server drives every plan: a state is server logic, a task of a role done by a worker, or an operator wait whose links the operator's two clients serve; no model drives a plan state, and the plan and epic representations are views.
