== Overview

This document specifies the authoritative filesystem layout for *plan-marshall-mcp* (`PM-MCP`), covering the repository-scoped workspace tree (`.marshall/`), the machine-wide instance directory `<PM_MCP_BASE>` (default `~/.plan-marshall-mcp/`, including the machine's operator files, the machine scope, and the file credential store `credentials/` where the operator chose it), and the per-project machine store `<PM_MCP_BASE>/projects/<project_id>/` that holds all server-owned state of one project. It defines path resolution rules, worktree isolation boundaries, the worktree lifecycle, and the separation from the state trees of `plan-marshall` (`.plan/`, `~/.plan-marshall/`), which `PM-MCP` never reads or writes.

Plan state never lives in the repository: every plan directory stays in the per-project machine store for its whole life and is never moved. The repository keeps git-tracked documents in `.marshall/` and only technical local data (worktrees and temporary files) in the git-ignored `.marshall/local/`.
