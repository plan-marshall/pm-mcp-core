== Overview

This document specifies the engine side of the machine-level security of *plan-marshall-mcp* (`PM-MCP`): the token-lane credentials of the provider integrations and their credential stores, the credential store as the operator's choice, provider verification, enrolment integrity, the enrolment with its lifecycle gate and release, a project's onboarding and release as processes, the security audit trail, and outbound HTTPS. The operator channel, the operator acts and the command-line binaries are specified in the link:../../../plan-marshall-documentation/doc/specification/cli-and-security.adoc[CLI, Coordination & Security Specification].
