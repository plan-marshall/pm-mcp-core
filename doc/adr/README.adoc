= Architectural Decision Records of `pm-mcp-core`
:nofooter:

An ADR records one design decision: the situation, what was decided, the alternatives and what follows. The ADRs of
this repository live in two kinds of directory:

* `doc/adr/`: the decisions that concern the whole repository.
* `{module}/doc/adr/{package}/`: the decisions of one package of a module.

== Numbering

ADRs are numbered per directory, with three digits: `NNN-{slug}.adoc`. A new ADR takes the next free number of its
directory. A number is never reused, not even for a superseded ADR. Two plans that write into the same directory at
the same time can take the same number; the plan that merges later renumbers its own ADR before the push.

== Writing an ADR

A new ADR follows the template link:template.adoc[`doc/adr/template.adoc`]. The template states the sections and what
each one holds. The layout of the module documentation is ADR
link:004-module-documentation-layout.adoc[004 The Module Documentation Layout].
