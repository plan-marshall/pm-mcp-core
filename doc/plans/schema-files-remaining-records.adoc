== Tasks

A move, plus the check the other store records already have. 25 blocks in seven documents become files.

. *Move the blocks* of `store-schemas/04-epic-and-change-ledger.adoc` (9), `05-metrics-and-quality-report.adoc` (2), `06-task-and-references.adoc` (6), `07-project-configuration.adoc` (2), `08-project-configuration-local.adoc` (3), `17-re-planning.adoc` (2) and `18-decision-records.adoc` (1).
. *A parity test per schema whose codec exists*: members, required members, enumerations and limits of the record against the file, in the form of `FindingSchemaParityTest`. These records are the ones for which the specification and the code could drift without any test noticing; the test is new, not a replacement.
. *A schema whose codec does not exist yet* (the trace matrix names them) is moved and named in the task of the package that builds the codec, which adds its test; the package index is not changed for it.
. *Where a schema file of the same record already lies in a module*, the block is replaced by an include of that file after the two statements are compared; the deviating one is corrected with evidence (the correction rule of the project skill `traced-implementation`), never worked around.
