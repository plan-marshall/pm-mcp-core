== Tasks

The code is the source of these lists, so the direction of the check turns: the document takes the list from the code. How the document gets it is open (link:../../../plan-marshall-documentation/doc/discussions/open-questions.adoc#generated-listings[Open Questions, `generated-listings`]); the package starts when the question is decided and its answer is written down here as the first task.

. *Apply the decision* of the open question to the log message table and to the three protocol lists: the listing is generated from the holder or the enum, or the list is dropped from the document and the document links the Javadoc.
. *Remove the check that parses the document*: `everyRecordDocumented` and `undocumentedRecordsAreFound` of `RuntimeLogMessagesTest`, and the two tests of `ProtocolVocabularyParityTest`, are replaced by what the decision requires (a test of the generator, or none).
. *The other holders*: `doc/LogMessages.adoc` documents the messages of the modules by ADR link:../adr/005-one-log-message-holder-per-module.adoc[005]; a holder whose rows no test checks follows the same form.
