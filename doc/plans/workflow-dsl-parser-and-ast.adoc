== What

* The line-oriented lexer and parser of the workflow DSL with every statement of the grammar, errors with file and line.
* The immutable AST records. `SourceLocation`, `WorkflowScope`, `LinkForm` and `LinkRelation` exist as declarations.

== Done When

Every construct of the grammar parses to its AST record and prints back; every malformed fixture is refused with its line. The fixtures are written for the test, never copied from a default unit (PM-WATCH-MOD-6).
