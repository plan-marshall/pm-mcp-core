== What

* Composition of a plan instance from templates and facts with provenance; immutable versions with the composition log and the closed set of composition events; the position rule.
* The instance in force rendered by the diagram generator as a read-only resource.

== Done When

A composed instance verifies; each composition event produces a new version with its cause; a version that lacks the current state or a state of the call stack is refused and the old one kept.
