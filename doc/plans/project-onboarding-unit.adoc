== What

* *Specification first*: the package writes the changes Onboarding a Project as One Process and Project Values over Machine Values into `plan-marshall-documentation` as part of its own work, once UC-PRJ-1 is agreed (link:../../../plan-marshall-documentation/doc/discussions/client-specification-changes.adoc#slicing[Specification Changes for the Clients, Packages]).
* *The unit*: `project.checkout` to `project.enrol` in a scope of its own per project being onboarded (several at once, the machine scope untouched), then the project setup; the consent kind `inspect_checkout`; detection of the remote, base branch, build wrappers, host tools, language servers, and scripts with a check line each; the id proposed from the remote; the enrolment written as `pm-operator enrol` writes it.
* *The setup's choices as operator waits* served to both clients; no session drives it.
* *Releasing a project* (UC-PRJ-3): release and unenrol as operator acts of both clients, the release ending each plan as a cancel does and cancelling each epic with its plans.
* *The project's values over the machine's*: every aspect the machine's onboarding records, proposed from the machine and recorded for the project only when changed; `project_defaults` as the machine's value of the project's operator keys, one rule for all.
* *The projects of the machine*: favourites and their order in a machine store, recent and most used from the operator's acts in a project.
