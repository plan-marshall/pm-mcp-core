== What

* The enrolment store, one file per project, with `--pilot` and the compiled lifecycle gate.
* Enrolment integrity: the HMAC sidecar under the keyring key, verified in recovery and before every verify-not-resolve check, re-baselined only by the operator.
* The per-use checks of enrolment files that Milestone 2 left out (owner, mode, no symbolic link).
* `unenrol` is refused while the project has live work and leaves the project store in place.

== Done When

A tampered enrolment, a sidecar without its file and a file without its sidecar are each refused and audited; the lifecycle gate refuses a plan lifecycle on a closed gate; a pilot enrolment passes it.
