== Tasks

The specification sections named are the single statement of what each task builds.

. *The stage `usage`*: its probe tasks, the comparison with the harness's own record, and the values it settles: link:../specification/client-profiles/01-profile-schema.adoc#profile-verification[Client Profiles § Profile Verification], the stage table, row `usage`; link:../specification/client-profiles/01-profile-schema.adoc#headless-usage[§ Usage].
. *The stage `settings`*, its name added to the closed stage names of the verification record: § Profile Verification, the stage table, row `settings`; link:../specification/client-profiles/01-profile-schema.adoc#headless-inline-settings[§ Inline settings].

Left out: the other stages of the verification; the measured values of the shipped profiles (`client-profile-measured-values`).
