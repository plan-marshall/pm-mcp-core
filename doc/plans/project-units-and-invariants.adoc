== What

* The loader of project-owned units (`.marshall/config/*.pmwf`) with their declarations within compiled bounds.
* The compiled invariants of each phase and `FinalizePipelineValidator` over the project roster; a violation refuses the project's plan lifecycle with file and line and is never replaced by a default unit.
* The loader of the default units from `classpath:/workflows/`, which the assembly supplies.

== Done When

One refusing fixture per invariant and per declaration bound; a fixture project unit that violates an invariant refuses the lifecycle and names file and line.

== Hooks Left for Later Packages

The package checks what the syntax tree and the descriptors decide. The remainders are named hooks, each a code constant at its check, and stay open for the packages that own the runtime facts (ADRs `workflow-verify/015`, `workflow-finalize/003` and `workflow-unit/004` of `pm-workflow`):

* `INV-GEN-2`: only the operator API writes waiver records and every lookup logs a consumption; the primitive SPI offers no write capability.
* `INV-GEN-4`: the removed options a primitive reads from configuration at runtime (lane, Q-Gate mode, confidence threshold, merge method, self-review scope).
* `INV-REM-6`: the remediation counters are kept per plan and class and never reset.
* Validator rule 6: the `work_performed` clause, decided over the outcomes of a step.
* Validator rule 7: no refusal after the merge, decided over the outcomes of a step.
* Validator rule 8: the refusal of a finding whose source the filing step does not declare, at the write of the findings store.
* `project_step_unbound`: reading the project's `workflow.json` and the enrolment; the loader takes the declared steps and the bound step ids as inputs.
* `DefaultUnitInvariantTest` over the shipped default units, in `plan-marshall-mcp`.
