== Tasks

A rename only: no behaviour changes beyond the names. A record written with an old name or value is refused, not read: the readers accept only the new names, and no reader maps an old one (no backward-compatibility shim before 1.0; link:../../pm-core/doc/adr/core-store/081-the-decision-log-rename-reads-no-old-name.adoc[ADR core-store/081]). The intent record's `choices[]` and the one decider kind with `role` in place of `model`, `BuilderCheck` included, were delivered by #427 (`f3c0dd2d`).

. *Amendment source*: the `source` of an intent amendment (`amendments[]` of `status.json`, link:../specification/store-schemas/02-workflow-state-store.adoc[Store Schemas § Workflow State Store]) takes the decider kinds `operator`, `role`, `quorum`, `fact` (link:../specification/store-schemas/18-decision-records.adoc#decider-kind[Store Schemas § Decider Kind]); where the code reads it, the stored values `user`, `model` and `refutation` are refused, naming the value.
. *Decision log*: no code of the decision log exists yet; the package that builds it (link:decision-quorum-and-calibration.adoc[`decision-quorum-and-calibration`] and link:decision-engine.adoc[`decision-engine`]) writes `decision-log.jsonl`, the resource `pm://plan/{plan_id}/decision-log` and the decider kinds of this package from the start. Nothing named `decisions.jsonl` is written.
. *Integrity hold*: no code of this repository names `integrity_pause`; the hold reason `integrity_hold` and the refusal `integrity_held` (link:../specification/state-catalogue/01-conventions-generic-conditions.adoc#condition-integrity_breach[State Catalogue, `integrity_breach`]) are written with these names by the package that builds the hold.
. *Module documents*: the developer documents of the packages the remaining tasks change name the decider kinds; the ADRs stay as written.
