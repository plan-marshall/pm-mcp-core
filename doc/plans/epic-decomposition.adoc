== What

* *Specification first*: the package writes the change The Decomposition Is Reviewed into `plan-marshall-documentation` as part of its own work, once UC-STA-6 is agreed (link:../../../plan-marshall-documentation/doc/discussions/client-specification-changes.adoc#slicing[Specification Changes for the Clients, Packages]).
* The draft of the role `decompose` held apart from the ledger; the server's checks over it (disjoint surfaces of plans that may run together, no dependency cycle, a workstream per plan); the operator wait `decomposition.review` with keep, edit, drop, add, chat (the sub-workflow link:chat.adoc[`chat`] with the draft as its scope), and draft again, every model change through read-back; the commit only after the operator agrees and every check passes.
* A later run (decompose again, stale rows) over staged rows only, each change against the row it replaces; no plan of a new epic starts before its first decomposition is committed.
* Where `epic.decompose` and `epic.commit-decomposition` have already been implemented without the review, this package restructures them.
