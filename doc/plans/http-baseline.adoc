== What

* Every HTTP call goes through `cui-http`. `CiHttpClient` of `pm-provider-ci` already sends every request through the `HttpHandler` of `cui-http`, and the GitHub and GitLab clients reach HTTP through it; one guard test pins that, and no production code changes.
* Every test that involves HTTP runs against `cui-test-mockwebserver-junit5`. The hand-made `FakeServer` doubles on `com.sun.net.httpserver.HttpServer` of the three provider modules are deleted; each test class that used one carries `@EnableMockWebServer` and serves its canned responses from its own dispatcher, with no helper class. The library is a test-scope dependency of the three modules, its version managed by the parent chain.
* The cross-origin tests keep their meaning: the one mock web server is addressed as `127.0.0.1` and as `localhost`, two origins on one machine.
* Out of slice: `pm-provider-sonar`, `pm-provider-git` and `pm-runtime`, which hold no HTTP test server; `FakeBus` of `pm-runtime`, a D-Bus fake on a Unix socket and not HTTP; any production change in `CiHttpClient`.
