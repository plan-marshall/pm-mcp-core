== What

* The bounded verification step of the startup order.
* Drain: the runtime ends only after its drain, bounded by the drain timeout of the machine configuration.
* Per-project crash recovery, run lazily per project and in a background pass after the bind.
* The periodic sweep, and the detection of a runtime whose version differs from the installed binaries.
* Jobs and workers join each of these in Milestone 4; this task leaves the seams they need.
