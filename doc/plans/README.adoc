One file per work package and this index. How the work is planned, what a package file holds, when a package is ready, and what happens to a package when it is done are stated only in link:../../../plan-marshall-documentation/doc/developer/project-setup.adoc#_planning_the_work[Project Setup § Planning the Work]. The links assume the repositories checked out beside each other; they do not resolve in the web view of a single repository.

The modules of this repository are listed only in the link:../../../plan-marshall-documentation/doc/specification/module-structure.adoc[Module Structure Specification]; each package file names where it lands.

[#packages]
== Packages

The status of a package is `open`, `blocked`, `done` or `dropped`; a `dropped` row names its reason. Dependencies are named by package id, a package of another repository as `<repository>` / `<id>`. The work packages of the other repositories: link:../../../pm-mcp-clients/doc/plans/README.adoc[`pm-mcp-clients`] and link:../../../plan-marshall-mcp/doc/plans/README.adoc[`plan-marshall-mcp`].

== How to Work a Package

As link:../../../plan-marshall-documentation/doc/developer/project-setup.adoc#_planning_the_work[Project Setup § Planning the Work] states. A package adds its log records as link:../adr/005-one-log-message-holder-per-module.adoc[ADR 005] states, and keeps its documents where `CLAUDE.md` places them.
