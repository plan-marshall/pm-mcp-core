== What

* Python reference scripts of `plan-marshall` against the Java primitives over shared fixtures; the legacy mapping lives in test code only; each legacy format is re-verified against the latest `plan-marshall`.
* First used by the `Ported` stores and primitives of this stage.

The harness runs one `Ported` primitive against its reference script and fails on a planted difference; no production class reads a legacy format.
