== What

* The convention for the tests of the `Ported` scripts: each script is adapted one at a time, with the original script and its pytest suite as the guide. The Java tests and their test data are written from it; the legacy mapping lives in test code and test data only.
* The tests run in Java and Maven alone. The build, CI, and every workflow need no Python interpreter and no checkout of `plan-marshall`; no run compares the Java result with a Python result.
* The original is `plan-marshall` at the commit the migration inventory pins. The pin is advanced deliberately, in one change that updates the inventory and verifies each legacy format again at the new commit.
* First used by the `Ported` stores and primitives of this stage.
