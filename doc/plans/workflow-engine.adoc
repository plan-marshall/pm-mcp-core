== What

* The deterministic interpreter: call stack, guards, loop-back budgets, sub-workflow execution with exit contracts.
* The workflow state store of a scope, written through the store substrate.
* Every wait is an engine event; the waits a model holds are link:waits.adoc[`waits`].
