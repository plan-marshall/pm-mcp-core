== What

* *Implements* link:../../../plan-marshall-documentation/doc/specification/module-structure.adoc#forgejo[Module Structure § Codeberg and Forgejo (`pm-provider-forgejo`)] (`PM-EXEC-5`, `PM-TECH-2`).
* The CI contract of `pm-provider-ci` over the Forgejo REST API (`/api/v1`) on the shared origin-pinned HTTP base, the native variant only, `ci.issue-view` and `ci.issue-comment` first, then the rest of the contract for a project whose remote is on a Forgejo forge; the findings contract of `pm-core` for its pull request reviews.
* The host detection (`codeberg.org`, else a probe of `/api/v1/version`) for the derived fact `ci_provider`; the value `forgejo` in every closed list of providers and integrations (the team's `ci_provider` override, the machine's provider defaults, a project's integrations, the audit's integration records); the credential key `forgejo`, whose entry's `url` names the forge's host.
