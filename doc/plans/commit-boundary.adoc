== Tasks

The specification sections named are the single statement of what each task builds.

. *The protected-path decision at the commit check*: the server asks the operator one question over the diff of exactly the touched protected paths, `accept` or `refuse`, and a `refuse` leads to a `fix` task; the family of protected paths is unchanged: link:../specification/phase-workflows/03-q-gate-and-execute.adoc#protected-paths[Phase Workflows § Protected Paths].
. *The main-checkout clause made conditional on confinement*: the guard's check holds only under `confinement: unavailable`, and under confinement the main checkout is no concern of a plan, so the operator's own edits there never concern one — the clause this package decides; the guard's code and its documentation (`provider-git-primitive.adoc`, the `entry_baseline` description, ADR 006) are `worker-write-set-and-main-checkout-guard`'s (PLAN-V2-193, staged): link:../specification/job-runtime/02-confinement-and-environment.adoc#_linux_filesystem_confinement_landlock[Job Runtime § Linux Filesystem Confinement]; link:../specification/store-schemas/02-workflow-state-store.adoc#_workflow_state_store_mcpstatus_json[Store Schemas § Workflow State Store], `entry_baseline`.
. *The lift removal*: a path the plan declares no longer lifts a protected path, and the family stays what it was — the decision this package owns; the matcher's code and the `references.schema.json` `unplanned_changes` wording are `lane-entries-and-realized-composition`'s (PLAN-V2-190, staged): link:../specification/phase-workflows/03-q-gate-and-execute.adoc#protected-paths[Phase Workflows § Protected Paths]; link:../specification/store-schemas/06-task-and-references.adoc[Store Schemas § Task and References].

Left out: the code and the documentation wording of both parts — the protected-path matcher and the `unplanned_changes` sentence (`lane-entries-and-realized-composition`, PLAN-V2-190) and the main-checkout guard with its `entry_baseline` description and ADR (`worker-write-set-and-main-checkout-guard`, PLAN-V2-193); this package owns the decisions those parts implement.
