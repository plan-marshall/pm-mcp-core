== What

* Atomic writes, the per-scope transaction journal with roll-forward at recovery, and the fixed write order of a transaction that writes outside its scope.
* The JSONL append discipline with tail repair under the store's lock.
* Store digest verification through the journal, with the sidecar outside the protected stores; a mismatch decided only under the store's lock.
* `format_version` on every document and record: exactly the current version is accepted, any other refused as `format_outdated` or `format_newer`.

== Done When

Crash-point tests: a kill between any two writes of a transaction is completed by recovery; a torn last JSONL line is repaired at the tail only; an out-of-band edit is detected on the next locked read and reported unverified by a lock-free reader; a document of another `format_version` is refused with its file named.
