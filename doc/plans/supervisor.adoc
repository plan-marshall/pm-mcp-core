== What

* One supervisor per project and role: starting fresh and warm workers within the role's count and the model slots, acknowledgement, silence and exit detection, idle and token-budget recycling, ending and fencing, the start-failure guard.

== Done When

With a fixture harness and a virtual clock: each loss is detected at its deadline and never before; a start failure repeated to the guard's count ends the role's starts.
