== What

* The detection of a stalled scope for `pm-operator status`. It reads scope stores that Milestone 3 delivers: plan this task after the store substrate of Milestone 3, or deliver the detection over a fixture store and wire the real stores then; decide in the trace matrix.

== Done When

A scope past its threshold is reported stalled, one below it is not; the threshold comes from the timeouts specification.
