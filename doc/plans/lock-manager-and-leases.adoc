== What

* One lock manager for every acquisition: one in-process lock per key and at most one OS `FileChannel.lock()` per lock file; the one total lock order asserted on every acquisition, an out-of-order acquisition refused as `internal_fault` with an audit record.
* Sibling lock files for every store replaced by atomic rename; lock paths outside the directories they protect.
* Lease records for the long-lived claims, claimed and released under a short transaction lock; the stale lease sweep.
* Lock-free snapshot reads of the stores.
