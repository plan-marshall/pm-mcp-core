== What

* The bounded long-poll and the progress-reset wait, selected by the server from the client profile and the request's progress token, for the only waits a model holds: `pm_wait`, and a running `pm_build` from Milestone 6 on.

== Done When

With a virtual clock: a bounded wait answers at its window; a progress wait emits no gap longer than the interval; the selection follows profile and token in all four combinations.
