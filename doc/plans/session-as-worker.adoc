== What

The specification has no interactive session as a worker: a harness is a worker only as a job the runtime launches (link:../../../plan-marshall-documentation/doc/specification/workflow-dsl/02-units-jobs-decisions.adoc#clients-only[Workflow DSL § All Interaction in the Operator's Clients]), and the requirement `PM-WORK-5` and the section Model Work § The Session as Optional Worker are removed. Nothing of this package is to be built; it waits for the operator's decision to drop it (link:README.adoc#packages[index]).

* (removed) A session of an eligible host takes tasks of `read_only` roles that set `session_first`; otherwise the supervisor serves them.

== Done When

A session of a profile with `session_tasks: false` is never offered a task; a fenced session loses its lease.
