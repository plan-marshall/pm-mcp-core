== What

* The role artifact schema, the shipped, machine and project sets with their override, validation against the client profiles, and the composition checks.
* The one model caller that turns a `job llm` state into queue tasks from the artifact of the role it names.
* The shipped set is read from `classpath:/roles/`, which the assembly supplies; tests use fixture roles.
