== What

* The daemon composes the write and read sets of each job and records the confinement level and the Landlock ABI that `pm-exec` reports.
* The job environment table built from scratch per job type, the rows of the CLI variant included.
* The per-project build daemon store, so that no build daemon serves jobs of two write sets.
* The enrolment opt-in `container_engine: docker`; without it the engine's sockets are withheld.
* No session bus for any job; the runtime socket as an own read rule of every worker.

== Done When

Linux tests under Landlock: a write outside the write set and a read of `<PM_MCP_BASE>` are refused; a confined Gradle build proves the registry option; the Docker socket is unreachable without the opt-in; the job record carries level and ABI. The macOS run records `unavailable`.
