== What

* The task queue store: queue task records and task leases per worker generation.
* The task protocol: offers, acknowledgement, leases, fencing, task outcomes and re-offers, and skill delivery per generation.
* The compiled `worker-task` unit is content of the assembly; this package proves the protocol against a fixture unit.
