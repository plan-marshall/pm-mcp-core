== Tasks

A move only, as in link:schema-files-tested-records.adoc[`schema-files-tested-records`]. 22 blocks in four documents become files, each in the module that owns its codec.

. *Move the blocks* of `store-schemas/11-enrolment-store.adoc` (1), `12-machine-stores.adoc` (18), `13-leases-integrity-testing.adoc` (1) and `15-screening-and-grants.adoc` (2).
. *Tests read the file*: `AuditSchemaParityTest` (pm-core) and `CredentialStoreMoveRecordParityTest` (pm-runtime) replace the block by the file. The credential test no longer extracts members from the schema text with regular expressions (`PROPERTY`, `REQUIRED`): it parses the file, as the tests of pm-core do through `SchemaResource`. The helper is reachable from pm-runtime through `pm-core:tests` (link:../adr/012-generator-artifacts.adoc[ADR 012]).
. *The records without a test*: the move record is the only machine-store record with a parity test besides the audit; for every other schema of the four documents whose codec exists, add the parity test over the file the way `AuditSchemaParityTest` has it. A schema whose codec does not exist yet is moved and named in the task of the package that builds the codec.
