== Tasks

The specification sections named are the single statement of what each task builds. The parsers build on the result model and the JVM parsers of `core.build` (link:../../pm-core/doc/developer/core-build.adoc[`core.build` Developer Guide]); `worktree_sha` and the ingestion validator stay as they are.

. *The coverage report parsers* (JaCoCo, Cobertura, LCOV, Istanbul): link:../specification/job-runtime/03-parsers-and-gates.adoc#_native_coverage_report_parsers[Job Runtime § Native Coverage Report Parsers].
. *Gate honesty*: population, gate coverage, test-scope divergence with `skipped_tests`, baseline separation and the untracked side state: link:../specification/job-runtime/03-parsers-and-gates.adoc#_gate_honesty_verification[Job Runtime § Gate Honesty Verification]; link:../specification/job-runtime/03-parsers-and-gates.adoc#side-state[§ Untracked Side State].
. *The adaptive timeout*: link:../specification/job-runtime/03-parsers-and-gates.adoc#_adaptive_timeout_learning[Job Runtime § Adaptive Timeout Learning]; link:../specification/store-schemas/09-derived-facts-and-build-timings.adoc#build-timings-store[Store Schemas § Build Timings Store].
. *The failure evidence per class*: link:../specification/job-runtime/03-parsers-and-gates.adoc#evidence-gathering[Job Runtime § Evidence Gathering per Failure Class].

Left out: the snippet provenance provider, which belongs to the code analysis contract.
