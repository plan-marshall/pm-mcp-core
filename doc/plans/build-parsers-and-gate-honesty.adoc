== Tasks

The specification sections named are the single statement of what each task builds. The parsers build on the result model and the JVM parsers of `core.build` (link:../../pm-core/doc/developer/core-build.adoc[`core.build` Developer Guide]); `worktree_sha` and the ingestion validator stay as they are.

. *Gate honesty*: population, gate coverage, test-scope divergence with `skipped_tests`, baseline separation and the untracked side state: link:../specification/job-runtime/03-parsers-and-gates.adoc#_gate_honesty_verification[Job Runtime § Gate Honesty Verification]; link:../specification/job-runtime/03-parsers-and-gates.adoc#side-state[§ Untracked Side State].
. *The build-neutral derivation of the freshness gate*: the gate derives from the latest succeeded build row — `git diff --name-only <head>..HEAD`, the paths the status reports dirty now and, when the build ran on a dirty tree, the paths dirty then, all classified by the build map — so a change of build-neutral paths alone keeps the notation fresh and any other change makes it stale; the task also writes the build row's new members (`HEAD`, the paths dirty at build time, the test files the plan changed against `base_ref` with the digest of the plan's own diff of each, and the identities of the failed tests of its parsed result); the reconcile stamp's removal is `change-ledger-build-row-and-freshness-reconcile`'s: link:../specification/phase-workflows/03-q-gate-and-execute.adoc#build-neutral-since-build[Phase Workflows § Worktree Freshness Gate]; link:../specification/store-schemas/04-epic-and-change-ledger.adoc#_change_ledger_record_change_ledger_jsonl[Store Schemas § Change Ledger Record].
. *The adaptive timeout*: link:../specification/job-runtime/03-parsers-and-gates.adoc#_adaptive_timeout_learning[Job Runtime § Adaptive Timeout Learning]; link:../specification/store-schemas/09-derived-facts-and-build-timings.adoc#build-timings-store[Store Schemas § Build Timings Store].
. *The failure evidence per class*: link:../specification/job-runtime/03-parsers-and-gates.adoc#evidence-gathering[Job Runtime § Evidence Gathering per Failure Class].
. *The changed lines without coverage*: the line records of the coverage parsers and their join with the plan's diff, `uncovered_changes` with its causes: link:../specification/job-runtime/03-parsers-and-gates.adoc#changed-uncovered[Job Runtime § Changed Lines without Coverage].

Left out: the snippet provenance provider, which belongs to the code analysis contract.
