== Tasks

The specification sections named are the single statement of what each task builds. The composer, the store of versions and sub-unit texts, and the rendering are built (`plan-instance`, link:../../pm-workflow/doc/developer/workflow-plan.adoc[Plan Instance Developer Guide]).

. *The composition events and their triggers*, server events in the entering transaction, operator and configuration events through one entry point with the position rule: link:../specification/workflow-dsl/09-plan-instance.adoc#_versions_composition_events[Workflow DSL § Versions & Composition Events]; link:../specification/workflow-dsl/09-plan-instance.adoc#composition-rules[§ Composition Rules].
. *The version in force*: `instance_version` as a field, the engine running the composed units and the stored sub-unit texts: § Versions & Composition Events; link:../specification/store-schemas/14-plan-instance-waivers-questions.adoc#plan-instance[Store Schemas § Plan Instance]; link:../specification/store-schemas/02-workflow-state-store.adoc[§ Workflow State Store].
. *Rules 13 and 14 at composition*, with the skill catalogue read through a port: link:../specification/workflow-dsl/04-ast-node-model.adoc#static-verification-rules[Workflow DSL § Static AST Verification Rules]; link:../specification/model-work/01-roles-and-configuration.adoc#role-sets[Model Work § Role Sets & Precedence]; link:../specification/model-work/10-decision-quorum.adoc#model-identity[§ Model Identity].
. *The instance resources* (the version's text with its header, the diagram of the version in force, the status): link:../specification/workflow-dsl/09-plan-instance.adoc#_display[Workflow DSL § Display]; link:../../../plan-marshall-documentation/doc/specification/mcp-tools/03-resource-uris.adoc#_normative_resource_uri_templates[MCP Tools § Resource URI Templates].

Left out: the callers of the operator events and of `start` and `replan` (link:start-from-clients.adoc[`start-from-clients`], link:process-designer.adoc[`process-designer`], link:plan-and-epic-control.adoc[`plan-and-epic-control`], link:re-planning.adoc[`re-planning`]); the bindings to the resource URIs and to the process resource, which are the assembly's in `plan-marshall-mcp`.
