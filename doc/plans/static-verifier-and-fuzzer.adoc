== What

* The static verifier: every referenced primitive exists, link parameters match the parameter record, every sealed outcome is handled, every state is reachable, every non-terminal state has an exit, link identifiers are unique per state, released state names are preserved or migrated.
* The transition fuzzer over verified units.
* Role checks join with the role sets of Milestone 4, skill checks with Milestones 7 and 14; leave the seam.
