= Log Messages
:toc: left
:toclevels: 3
:nofooter:

Every module that logs has one holder of its messages, in its own `log` package and with its own prefix. A module logs only through its own holder and that of `pm-core`. A provider module gets a holder `de.planmarshall.provider.<x>.log.<X>LogMessages` with the prefix `PM_PROVIDER_<X>` with its first message.
Identifier ranges in every holder: INFO 001-099, WARN 100-199, ERROR 200-299; a new message takes the next free identifier of its level.
The messages the assembly `pm-mcp-server` logs, and no module of `pm-mcp-core`, are held by `RuntimeLogMessages` until the assembly takes them over; the Javadoc of each such record names the component in the assembly that logs it.

The tables below are generated from the holders: each states the identifier and the template of every record, and nothing a change to a holder would leave stale. What a record is for, and which component logs it, is the Javadoc of the record; the holder link of each section leads to it. The listing of a holder is a committed file below `doc/`, and each module's holder test compares it byte for byte with a fresh generation.
