== Overview

This document is the index of the technical specifications of the engine of *plan-marshall-mcp* (`PM-MCP`): the specifications the modules of this repository (`pm-core`, `pm-workflow`, `pm-runtime` and the provider modules) implement, kept beside the code so that a work package changes code, tests and specification in one pull request. The requirements (link:../../plan-marshall-documentation/doc/Requirements.adoc[Requirements Document]), the use cases, the roadmap, and the specifications of the other repositories and those every repository shares (the link:../../plan-marshall-documentation/doc/specification/module-structure.adoc[Module Structure Specification] among them) stay in `plan-marshall-documentation` (link:../../plan-marshall-documentation/doc/Specification.adoc[its Specification index]). The watch items of the specifications here are collected in the link:ImplementationWatch.adoc[Implementation Watch of `pm-mcp-core`]; the archetypes that span all specifications stay in link:../../plan-marshall-documentation/doc/implementation-watch/cross-cutting.adoc[cross-cutting.adoc]. What each implemented requirement is implemented by, verified by and documented in is recorded in link:Traceability.adoc[Traceability].

The lifecycle states of a specification (`PLANNED`, `IN PROGRESS`, `REFERENCE`, `DEPRECATED`), the deletion of implemented sections and the traceability rules are those of the link:../../plan-marshall-documentation/doc/Specification.adoc[Specification index] of the documentation; they apply here unchanged, with the links to the requirements written as relative sibling paths into `plan-marshall-documentation`.

== Technical Specification Index

The links between the documents of this tree are relative; a link into `plan-marshall-documentation` is a relative sibling path that resolves with the repositories checked out beside each other, and the documentation links into this tree with absolute `https://github.com/plan-marshall/pm-mcp-core/blob/main/doc/...` URLs. Both directions are checked by `trace.py` of the documentation, the required check of both repositories.
