What each requirement of the link:../../plan-marshall-documentation/doc/Requirements.adoc[Requirements Document] that the modules of this repository implement is implemented by, verified by and documented in. A work package adds the lines of the requirements it implements here, in its own pull request: `Implementation:` links the production classes, `Verified by:` the automated tests, and `Documentation:` the developer documentation of the module (`{module}/doc/developer/`) and, where it exists, the concept and user documentation of `plan-marshall-documentation`. The links into this repository are relative; a requirement keeps its link to the specification it is specified in, and the implemented sections of that specification are deleted (link:Specification.adoc[Specification]).

A requirement implemented in another repository is traced there, or, for code without documents of its own, in the requirement itself.
