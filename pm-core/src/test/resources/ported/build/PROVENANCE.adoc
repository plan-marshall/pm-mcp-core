== What a `*.log` file is

A `*.log` file beside a fixture is the *original's own log fixture*, copied byte for byte. It is test data, never an
oracle: no test runs Python, starts a `plan-marshall` script, reads the sibling checkout, or compares a Java result with a
Python result, live or recorded.

== What a `*.txt` file is

One scenario per file, headed `original: plan-marshall@<commit> <pytest path>::<case>` when it is derived from a pytest
case, or `deliberate: <name>` when it asserts a deliberate change of this port (never a value of the original). The
roster `original-cases.txt` of each directory lists every case of its suites, mapped to its fixtures or excluded with a
reason.

== Pinned by hand, never by the suite

The expected values of a `*.txt` fixture are read out of the original log by hand, the way the pytest suite derives them.
Where a comment names the original's own assertion (for example "the original asserts the message list"), the fixture
carries the same expectation.
