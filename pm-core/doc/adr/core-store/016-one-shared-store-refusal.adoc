= ADR 016: One Shared `StoreRefusal` for Every Store
:nofooter:

== Status

Accepted

== Date

2026-10-11

== Context

Format-version refusals existed only as nested types of the lease codec (`LeaseCodec.Refusal`, `FormatException`).
The work package requires `format_version` on every document and record: exactly the current version is accepted, any
other refused as `format_outdated` or `format_newer`.

== Decision

One shared `StoreRefusal` (outcomes absent, unreadable, `format_outdated`, `format_newer`) and `StrictJson` replace the
nested `LeaseCodec.Refusal` and `FormatException`. `LeaseCodec`, `LeaseStore` and `StaleLeaseSweep` of `pm-runtime`
move onto them.

Rationale not recorded.

== Alternatives Considered

Alternatives not recorded.

== Consequences

* A document of another `format_version` is refused with its file named.
* Later stores refuse through the same type: the workflow status store (ADR 001) and the enrolment store (ADR 019)
  report a schema violation as a `StoreRefusal`.
