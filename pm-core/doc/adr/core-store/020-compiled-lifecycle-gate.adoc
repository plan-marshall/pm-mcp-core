= ADR 020: The Lifecycle Gate Is Compiled
:nofooter:

== Status

Accepted

== Date

2026-10-12

== Context

The work package asks for the enrolment store with `--pilot` and the compiled lifecycle gate: the gate refuses a plan
lifecycle while it is closed, and a pilot enrolment passes it.

== Decision

`LifecycleGate` in `core.store` is compiled into the release (`LifecycleGate.RELEASE`), never a setting: no
configuration key, environment variable or file opens it. While it is closed, a plan or an epic is created only in a
project enrolled as a pilot (`pilot: true`), and every other project is refused with `lifecycle_closed`.

Rationale not recorded.

== Alternatives Considered

Alternatives not recorded.

== Consequences

* A test proves that the gate refuses a plan lifecycle on a closed gate and that a pilot enrolment passes it.
* Opening the gate is a change of the release, not of a project's configuration.
* An edited enrolment is refused by its integrity check in `pm-runtime` before the gate reads it (link:../../../../pm-runtime/doc/adr/runtime-enrolment/001-integrity-hmac-in-the-runtime.adoc[`runtime-enrolment` ADR 001]).
