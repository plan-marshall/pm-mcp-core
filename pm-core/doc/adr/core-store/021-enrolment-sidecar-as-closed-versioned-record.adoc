= ADR 021: The Enrolment Sidecar Is a Closed, Versioned Record
:nofooter:

== Status

Accepted

== Date

2026-10-12

== Context

Enrolment integrity is an HMAC sidecar beside each enrolment file, re-baselined only by the operator. When the operator
accepts an edit of an enrolment file (`accept-edit`), the recorded and the current state of the file have to be shown
side by side.

== Decision

The enrolment sidecar (`EnrolmentSidecar`) is a closed, versioned record with the members `format_version`, `size`,
`sha256` and `hmac`. This is the operator-approved requirement correction C1; it changes the wording of the
specification only, not its intent.

The record carries size and SHA-256 so that `accept-edit` can show the recorded versus the current size and SHA-256.

== Alternatives Considered

Alternatives not recorded.

== Consequences

* The sidecar is refused like every other closed record when it carries another `format_version` or an unknown member.
* The C1 wording went into the specification with the companion documentation pull request.
