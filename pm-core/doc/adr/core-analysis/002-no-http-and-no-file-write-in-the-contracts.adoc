= ADR 002: No HTTP and No File Write in the Findings and Analysis Contracts
:nofooter:

== Status

Accepted

== Date

2026-10-11

== Context

The findings and code-analysis contracts of the foundation are declarations, serialization and validation only: no
HTTP call and no store write. The store write comes with the store substrate, the Sonar implementation with roadmap
Milestone 6.

== Decision

* The ArchUnit test `AnalysisBoundaryArchTest` fails when a class of `core.analysis` or `core.findings` references a network API or writes a file. It is proven against control fixtures that must fail.
* `FindingScope` is shared by `core.findings` and `core.analysis`, so that the dependency between the two packages stays one-way.

The guard keeps the packages to declarations, serialization and validation.

== Alternatives Considered

Alternatives not recorded.

== Consequences

* An HTTP call or a file write in either package fails the build; the provider implementation and the store write live elsewhere.
* `CodeAnalysisProvider` (`id()`, `status(target)`, `issues(target)`) and `CodeAnalysisProviderRegistry`, whose members are passed to its constructor, are declarations that an implementation outside these packages fills.
