= ADR 002: A Provider-Neutrality Guard With One Named Exemption
:nofooter:

== Status

Accepted

== Date

2026-10-11

== Context

Nothing in `pm-core` may name a single provider: the finding types carry `source: analysis` with the provider's id and
`provider_ref.issue_key`. No guard kept provider names out of `pm-core`.

== Decision

* The ArchUnit test `ProviderNeutralityArchTest` keeps provider names out of the packages of `pm-core`. It is proven against control fixtures that must fail.
* "Names a provider" is read as the identity of a provider module or analysis provider: a type, package or member name, or a dependency on a provider package.
* The two wire constants `GITHUB_PR` and `GITLAB_MR` of the closed store vocabulary `FindingSourceKind` are the single named exemption.

Rationale not recorded.

== Alternatives Considered

Alternatives not recorded.

== Consequences

* A class of `pm-core` that names a provider fails the build.
* Other constants that carry a provider's wire value use a neutral name: `ProjectEnrolment.Provider` names its constants `GH` and `GLAB` (wire values `github` and `gitlab`) so that the guard holds (link:../core-store/019-enrolment-schema-closed-at-every-level.adoc[`core-store` ADR 019]).
* `com.tngtech.archunit:archunit-junit5` is a test-scope dependency of `pm-core`, added with the operator's consent.
