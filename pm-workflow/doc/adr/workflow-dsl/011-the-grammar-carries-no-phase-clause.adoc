= ADR 011: The Grammar Carries No Phase Clause
:nofooter:

== Status

Accepted

== Date

2026-10-28

== Context

The unit grammar admitted `phase <value>` on a state and `phase inherit`, and the printer emitted the clause, so a
round trip preserved it. With the plan unit split into phase sub-workflows (ADR workflow-ast 003) no unit and no
state declares a phase, and a surviving clause would be a second, disagreeing source of a phase.

== Decision

* `WorkflowParser` no longer reads `phase` as a clause or `inherit` as a value of it; `phase` stays a reserved word of
  the grammar so a unit that still writes it is refused by name rather than parsed as a state identifier.
* `WorkflowPrinter` emits no phase line, so a printed unit never carries the removed clause.
* The printer and the parser keep their one-line-per-construct agreement: the printer writes only what the parser
  reads (Rule 15.3 of the epic's checklist).

== Alternatives Considered

1. *Refuse the clause with a deprecation warning.* Rejected: nothing is released, and the epic keeps format version 1
   in place (R13), so the construct is removed rather than deprecated.

== Consequences

Every fixture and unit that carried the clause is rewritten in the same pull request. A unit that still writes
`phase` fails the parser, which is the intended refusal; the removal is not recoverable through a compatibility path.
