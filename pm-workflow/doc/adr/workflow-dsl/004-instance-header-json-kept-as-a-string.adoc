= ADR 004: The Instance Header Is Parsed with Its JSON Kept as a String
:nofooter:

== Status

Accepted

== Date

2026-10-11

== Context

A plan instance file starts with an instance header line that carries JSON. The parser has to read that line into the
AST and to check its structure; the checks of the header schema beyond that structure belong to another package.

== Decision

* `InstanceHeaderReader` parses the instance header line into the AST record `InstanceHeader`, with its JSON kept as a string.
* `jackson-core`, with its version managed by the parent POM, is the only new dependency of `pm-workflow`.

Rationale not recorded.

== Alternatives Considered

Alternatives not recorded.

== Consequences

* `InstanceHeaderReader` checks the structure of the line: one JSON object, the required members with their types, no member named twice at any depth and no content after the object. It refuses anything else with a `HeaderRefusal`.
* The checks of the header schema beyond that structure (constants, enumerations, patterns, members the schema does not allow), and the `partVersions` and `derivedFrom` bookkeeping, are left to other packages; the reader keeps the JSON as read and does not interpret it further.
* No log message, no HTTP call and no test dependency was added with the parser.
