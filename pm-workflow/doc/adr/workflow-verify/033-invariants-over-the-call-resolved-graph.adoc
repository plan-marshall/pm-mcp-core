= ADR 033: The Compiled Invariants Are Decided over the Call-Resolved Graph
:nofooter:

== Status

Accepted

== Date

2026-10-28

== Context

`INV-INIT-1`, `INV-REFINE-1`, `INV-OUTLINE-1/2`, `INV-PLAN-1`, `INV-EXEC-1..3` and `INV-FIN-1..6` are written over the
merged plan unit: "every path into `phase-4-plan` …", "every path into the merge passes `finalize.merge-gate`". With
the phases as separate sub-workflows, each cross-phase edge of the merged unit becomes an exit plus a call, so a
check over a single unit's own graph would silently drop every guarantee that crosses a phase boundary. `INV-GEN-4`
forbids weakening a guarantee. The operator decided on 2026-10-27 that the invariants are decided over the
call-resolved graph of the composed version.

== Decision

* `CallGraphExpansion` builds the graph the engine runs: a call state's own transitions are replaced by an edge into
  the callee's named entry, and a terminal of the callee returns to the transitions of every call site that routes its
  outcome. The expansion is verifier-only; nothing is inlined in storage.
* The expansion is context-insensitive: a callee's states appear once, and a terminal returns to every call site that
  routes its outcome. The union is the conservative direction for a path guarantee.
* The phase invariants apply to the plan unit (over the expansion) and to the phase sub-workflow whose states they
  judge (over its own graph), so each unit is held to its own part of the guarantee.
* `INV-GEN-1` compares the terminals of the unit itself, never those of its expansion: a sub-workflow bound by another
  axis variant is not a missing terminal. A Rule 9 violation of the finalize phase maps to `INV-FIN-3` for the plan
  unit and for the finalize phase unit.
* The paragraph that states the call-resolved reading is added to Workflow DSL 04 and 06; the matched controls are the
  refusing cases of `CompiledInvariantsTest` and their cross-phase pairs (`INV-EXEC-2`, `INV-FIN-*`).

== Alternatives Considered

1. *Per-unit invariants with declared exits.* Rejected by the operator on 2026-10-27: it weakens every cross-phase
   guarantee, which `INV-GEN-4` forbids.
2. *Inline the composed graph into storage (a merged unit again).* Rejected: it restores the merge the package
   removes and duplicates the composition the instance store owns.

== Consequences

A project unit is checked over its own graph; a composed plan over the union of its calls. A new cross-phase guarantee
is written over the expansion, and its refusing case is a mutation of a phase unit. A context-insensitive expansion
can report a path that no single call chain realises; the check must therefore name the unit and the state it reports,
which every violation does.
