## Specification Added Since The Package File

Merged outside the ledger on 2026-10-21 by the operator, specification only: #132 `672d746` (from the analysis `opus-5-5-prompting` of `plan-marshall-documentation`). The package file does not name it; this plan carries it (carried by the cleanup of 2026-10-22). The executing plan reads the named parts at its branch point and builds what they now say; the package file is deleted with the package as usual.

- **`attempt_end` per metrics row.** Every metrics row carries `attempt_end`, the end of its attempt as the queue task record holds it (`attempts[].end`): one of `closed`, `worker_lost`, `exited_without_submit`, `waited_again`, `budget`, `start_failure`, `restart`, `drain`, `paused`, `off_track`, `withdrawn`, `deadline_expired`, `suspended`, or `null` only for a task closed without an attempt (`cause_class: refused`). It is a required member of the row, so that the share of attempts that ended with a clean exit and no submission (`exited_without_submit`) is read per role, harness version, model and effort — `doc/specification/store-schemas/05-metrics-and-quality-report.adoc` (row schema) and invariant 5 "One Row per Attempt" of `doc/specification/model-work/09-completion-usage-and-spend.adoc`.

Folded into deliverable 2 (the metrics row per task and job with its raw columns); no new deliverable. A test per value of the enum: the row copies the end of the attempt; a task closed without an attempt writes `null` with `cause_class: refused`.
