## The decisions
- **An `adopt` plan's base branch is the pull request's base.** The `source-pr` start's `ci.pr-view` reads it, and the start writes it as the plan's own `base_branch` (`overrides.json`) in the plan's creation transaction. Base Stamp states it, and `init.options` never asks it for an `adopt` plan. This is the one write to `overrides.json` that is not the operator's (phase-workflows/01 Plan Source Contracts and Base Stamp; workflow-dsl/09 Posture and base branch; store-schemas/14 Plan Overrides; filesystem-layout/03).
- **A dispatch refused `checks_pending` waits on the checks.** `merge.route-refusal` routes `checks_pending` to `finalize.merge-evidence-wait` over the same `HEAD`, with the lease released. `all_green` re-enters `finalize.merge-gate`, and the wait's own stall rule bounds it, not the server-rule retry budget. `checks_failed` keeps its route. Before, the re-entered gate reached the barrier, which does not observe a pending check, and re-dispatched until the budget was spent (state-catalogue/07 `finalize.merge-refused`, `finalize.merge-evidence-wait`; phase-workflows/06 Merge Path items 4 and 6; timeouts/01 Server-Rule Retry Budget; watch PM-WATCH-PHASE-83).
- **A required check red only through baseline failures hands the plan back at the barrier.** A red required CI check at `HEAD` whose every failure a `baseline_red` change-ledger row of the `worktree_sha` of `HEAD` covers ends the barrier `baseline_red_required`, which goes to `finalize.hand-back` with the lease released. The gap is `cause: baseline_red`, and it lists the checks and the base commit that shows them red. Before, `finalize.remediate-barrier-ci` returned `resolved` without charging a budget, and the barrier failed again on the same `HEAD` without end (state-catalogue/07 `finalize.merge-barrier`, /04 `finalize.hand-back`; phase-workflows/06 Merge Path item 5, /03 Baseline-Red Server Rule; workflow-dsl/08 `remediation.ci-failure`; watch PM-WATCH-JOB-25, the gap-cause scenario list of the fallback watch item in phase-workflows.adoc).
