## Objective

The specification now has a liveness guarantee (every non-terminal position is engine-progressing, a bounded wait, an operator wait or a resident rest), a bound for every awaiting primitive, the hold `overdue` with its two causes, the hold record's `awaited`, position and correlation ids, the prerequisite-cycle refusal, the runtime self-watch, the clock gap, the release of the model slot of an ended job, and the metric `work.waits`. The code follows none of it but the shape of the cycle rules (rules 11a and 11b), the stalled hold and the persisted model slots. No package text of `doc/plans/` names the work, so no plan that builds it is ready (Project Setup: a package text must exist before a plan is ready). This plan edits six package texts, adds three new ones and the index and traceability rows, gives each mechanism one named owner, and takes up the lines the previous package-text plan (PLAN-V2-210) left. It changes no specification and no code. The code plans themselves are staged by the orchestrator after this plan has merged.
