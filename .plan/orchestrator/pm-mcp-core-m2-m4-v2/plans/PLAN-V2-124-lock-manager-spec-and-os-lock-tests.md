## Objective

PLAN-V2-95 (#328, ADR `core-store/068`) moved the OS lock of a leaf key from the append-only store to the sidecar `<lock file>.lock`, because on POSIX closing any channel on a file drops every OS lock the process holds on it and every append, repair and last-line read of a JSONL store opens and closes one. The code and the module documentation say so. The shared specification still says the opposite in places, and the tests of the fix prove where the lock is taken and how often it is released, not that an append leaves it held. The plan:

1. Makes the specification true: one statement of the leaf lock in the section that owns the lock order, and the five places that state the defect or the old rule corrected by pointer to it (R05: condense and point), the imprecise wording tightened, and the reference that no longer exists reported.
2. Makes the OS lock of a leaf key shown by a test that can fail: the integration lane reads the lock from a second process for every kind of leaf key (the audit log's append, its torn-tail repair and its last-line read; the plan mailbox; a journal-shaped key), each with a recorded failing run against a scratch mutation; the unit lane says honestly that the in-process probe sees the JVM's lock table.
3. Marks what is POSIX-only with `@EnabledOnOs`, closes the conformance residues of the added tests, and states and pins the life cycle of the sidecar.

Facts the plan rests on, re-read at `d1fb719f`: the only production leaf keys are `LockKey.auditLog` (`LockKey.java` line 314), `LockKey.mailbox` (line 327, no production caller on `main`) and the three `new LockKey(LockLevel.LEAF, file, queueTaskId)` of `ActivityJournal` (lines 198, 269, 291); `FileLockManager.osLockFile` (lines 126 to 135) derives the sidecar for the leaf level only; the other stores that are file-locked append under `scope.lockKey()` and are not affected (`WaiverLog`, `ChangeLedger`, `QuestionLog`, per the landing). All line numbers are those of `origin/main` at `d1fb719f`; this plan re-reads them at the head.
