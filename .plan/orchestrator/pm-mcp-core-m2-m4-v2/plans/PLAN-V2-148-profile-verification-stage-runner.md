## Objective

PLAN-V2-147 builds the pure stage model, the evaluators and the writer; this plan builds what **produces the observations**: a `StageRunner` in `pm-runtime` that runs the stages in their order as confined probe and worker jobs, the harness scan and the login and model probes, and the stages that need a process. It runs on the listed worker read set, the socket list and the complete probe jobs of PLAN-V2-146. **It needs a real harness to mean anything:** the lane cannot run one, so every stage is built and proven against a **scripted fixture harness** (a test-written stub process), and no Done-when, document or commit message claims that a real harness was verified. The runner sits behind an injected port (`StageWorkers`, HYPOTHESIS) so that it is testable without the job runtime; the `harness.verify-profile` sub-workflow, the operator verbs and the install verb are in `plan-marshall-mcp` and `pm-mcp-clients` and are not built here.
